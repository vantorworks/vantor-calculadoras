# VANTOR — Calculadoras Shopee e TikTok Shop

Aplicativo estático com custo unitário, peças por kit, repasse e lucro por peça. Os dados são guardados localmente no navegador.

## Publicar no GitHub Pages
1. Crie uma conta em https://github.com/signup e confirme seu e-mail.
2. Crie um repositório **público** chamado `vantor-calculadoras` (necessário para GitHub Pages gratuito em contas pessoais).
3. Envie o conteúdo desta pasta para a raiz do repositório, incluindo `.github/workflows/pages.yml`.
4. Em Settings > Pages > Build and deployment, escolha **GitHub Actions**.
5. Em Actions, execute o workflow ou faça um commit na branch `main`.
6. O endereço usual será `https://SEU-USUARIO.github.io/vantor-calculadoras/`.

## Importante sobre atualização de taxas
Esta versão permite ajuste manual dos percentuais exibidos. **Ainda não possui atualização automática nem validação das políticas oficiais.** Para isso é necessário implementar um verificador com fontes oficiais verificáveis, histórico de vigência e testes de validação antes de alterar as regras. A hospedagem do GitHub Pages, por si só, não atualiza taxas.

Confira sempre o extrato de pedidos e as políticas oficiais antes de precificar.
